## Design Context

### Users

Personal portfolio visitors: prospective employers, collaborators, and clients evaluating
Raimov Xushnudbek's recent software work. The user confirmed equal emphasis on employers and clients. Prioritize project discovery and direct contact.

### Brand Personality

Expressive, precise, approachable. Show a developer who works across interfaces, services,
and mobile products, grounded in verified GitHub/GitLab project evidence.

### Aesthetic Direction

The user explicitly requested the style of https://rondesignlab.com/blog/work-in-progress
and motion inspiration from https://prompt-motion.com/?tag=product-ui.
Use Urbanist (one of the user's requested fonts and the reference's actual family),
an open light canvas, oversized solid typography, generous negative space, rounded
visual stages, and soft project-specific colors. The user explicitly requested real app
images: use official store images or captures of actual applications with sample data.
Never recreate a product interface as a substitute. Put Xushnudbek Raimov in the large
hero heading, and animate the personal monogram with a short, replayable entrance.

The approved logo is the standalone three-part geometric symbol based on the Xentam
reference (Tuintrick Studio, https://logosystems.app/logo/ls-xentam). The user chose
the lighter version: thinner branches, generous open spaces, and muted sage #789184.
Use the symbol without a name or dark enclosing tile in the header and browser icons.
Keep the full personal name in the hero. Preserve short, optional motion.

The user removed the separate TOK BOR Website card and all visible Buduar references.
Show Comfi as a selected project with its existing real website image. Keep the TOK BOR
platform and mobile work; those are distinct from the removed marketing website.

### Design Principles

- Let real projects and readable typography lead; preserve factual project descriptions.
- Use one coordinated entrance and purposeful product motion, with native scrolling.
- Keep motion interruptible, avoid perpetual decorative motion, and respect reduced-motion preferences.
- Provide visible project details, accessible filters, and direct contact on desktop and mobile.
- Private repositories remain private; publish no internal hosts, client data, or fabricated metrics.
